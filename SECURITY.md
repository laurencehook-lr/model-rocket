# Security policy

Model Rocket handles local routing for subscription-authenticated model traffic.
Please report suspected vulnerabilities privately and do not open a public issue containing exploit details, credentials, captured prompts, or customer data.

## Report a vulnerability

Use GitHub's private vulnerability reporting:

1. Open the repository's **Security** tab.
2. Select **Advisories**.
3. Select **Report a vulnerability**.

Include the affected commit or version, operating system and architecture, expected and observed behaviour, security impact, and the smallest synthetic reproduction you can provide.
Remove all real credentials, tokens, prompts, source code, and customer information.

The project is experimental and does not promise a response or remediation service-level agreement.
Please allow maintainers time to reproduce and assess the report before public disclosure.

## Scope

Reports about the current `main` branch and the latest published Model Rocket release are in scope.
Vendor services, vendor clients without Model Rocket, social engineering, denial of service requiring prior control of the local account, and reports without a reproducible Model Rocket impact are out of scope.

The documented vendor-policy limitations are governance concerns rather than software vulnerabilities.
